# The engine is a quick estimator, not a return-equivalent calculator

`calculateTotalTax` estimates 2025 federal tax with the statutory formulas, using bracket math rather than the IRS Tax Table, and rounds only for display. It must get the values and the order of calculation right for common returns: wages, interest and dividends, capital gains, Schedule C/E, K-1 income, the standard or itemized deduction, QBI, the OBBBA deductions, CTC, SE tax and NIIT. It deliberately does not reproduce return-only machinery: Tax Table lookups and line-by-line rounding, a full AMT calculation (Form 6251), the exact refundable CTC (Schedule 8812), the Additional Medicare tax on wages (Form 8959), per-spouse allocations, or rare eligibility edge cases (e.g. qualifying-surviving-spouse nuances, SSN requirements). We chose this because exact returns need per-spouse and per-document inputs the API doesn't collect, and the library's job is planning and comparing scenarios, not filing. Each omission is listed in the README so an estimate is never mistaken for a return.

**Consequences:** ledger rows in `docs/validation/` that only matter for an exact return are closed as out of scope, not fixed. Any row that changes a common-case estimate still gets fixed.
