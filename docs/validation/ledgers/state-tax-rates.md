## Summary

- **102 ledger rows:** 34 CORRECT, 28 WRONG, 39 MISAPPLIED, 1 STALE-COMMENT, 0 MISSING-GATE, and 0 UNVERIFIED.
- **26 of the 51 basic state/DC schedules contain wrong values.** Material examples include obsolete graduated schedules for Iowa and Louisiana, Hawaii’s pre-2025 brackets, New Mexico’s old structure, and outdated rates for Georgia, Idaho, Indiana, and Utah.
- **Correct rates are also applied incorrectly.** Mississippi omits its $10,000 zero-rate band; Ohio omits statutory base taxes; Connecticut and New York omit recapture computations; several filing statuses use the wrong schedule.
- Washington uses the **2024 $270,000 deduction instead of $278,000**, and applies its additional 2.9% rate before subtracting deductions. Massachusetts uses an unindexed $1 million surtax threshold.
- These state-law corrections apply under **both `useObbba2025` settings**. State taxable-income conformity may depend on federal changes, but that input calculation is outside this file.
- Read all **695 lines**, checked all 50 states plus DC against primary evidence, and ran read-only Bun checks. **No files changed.** Vermont’s final official schedule was read through an NBER mirror and corroborated against the department’s 2025 estimated-tax instructions.

## Open questions

- **Input contract:** Does `taxableIncome` mean each state’s correctly adjusted taxable income, or federal taxable income reused across states? This file cannot establish correct state deductions, exemptions, or OBBBA conformity upstream.
- **Result contract:** Is this an ordinary-income estimate before credits, or a return-ready state tax? Return-ready calculations require prescribed tables/rounding, applicable income-class computations, AGI-dependent rules, and separate surcharge handling where credit rules require it.
- **`widow` meaning:** The Alabama, Kansas, and Wisconsin findings assume federal qualifying-surviving-spouse status following a death in an earlier year. Death-year joint filing is a different case and needs an explicit mapping.
- **Washington preprocessing:** Are gains already adjusted for Washington allocation, exemptions, and allowable deductions before reaching this helper? Its argument name does not establish that.
- **Invalid inputs:** Missing/unknown states silently return zero, and unrecognized filing-status strings silently use S. Decide whether those are intentional application defaults or should be validation errors.
